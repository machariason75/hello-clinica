# High-resolution hero photos

Replaces the six slideshow photos with full-resolution, sharp versions
(980x735, cropped to the hero's 4:3 frame). No code changes needed.

Bonus: public/images/study-nclex.jpg (the NCLEX study scene) is included for
use on the Books section later — not wired in yet.

## Install
1. Extract over your hello-clinica folder, Replace the 6 files in
   public/images/medics/  (and the new study-nclex.jpg in public/images/).
2. Hard-refresh the browser:  Ctrl + Shift + R   (clears the old cached images).

These are local files, so they also deploy automatically when you push to
Vercel — nothing extra to do for going live.
